QUICK START (3 STEPS)
================================================================================

Step 1: Import the aggregator
  from dating_agent.profile_aggregator import profile_aggregator
  agg = profile_aggregator()

Step 2: Authenticate
  auth = agg.hinge_auth
  req = auth.request_phone_verification("+1-555-123-4567")
  verify = auth.verify_phone_otp(req['otp_id'], "123456")
  user_id = verify['user_id']

Step 3: Run sync
  result = agg.run_full_sync(user_id, limit=100)
  agg.export_sync_report("results.json")

Total time: 2-5 minutes

================================================================================
ERROR HANDLING
================================================================================

Automatic Recovery For:
  - Rate limiting (429) - exponential backoff + cooldown
  - Auth errors (401) - automatic token refresh
  - Network errors - retry with exponential backoff
  - Invalid data - skip record, continue processing
  - Database errors - transaction rollback
  - Timeout errors - retry with increased timeout

All errors logged with:
  - Error category
  - Recovery action taken
  - Detailed context
  - Timestamp

Common Issues & Solutions:
  Q: "User is not authenticated"
  A: Run verify_phone_otp() first

  Q: "Rate limit hit"
  A: System automatically backs off. Wait 60 seconds.

  Q: "Token expired"
  A: System automatically refreshes. Check logs.

  Q: "Invalid phone format"
  A: Use +1-555-123-4567 format

  Q: "OTP timeout"
  A: OTP expires after 5 min. Request new one.
